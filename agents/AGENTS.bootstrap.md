# oneup4real standards (bootstrap)

This block is managed by `npx oneup-standards sync-agents --global` and replaced on every run. Put your personal rules outside it.

- The full standard travels in each project's `AGENTS.md` (block "oneup4real/engineering-standards"). Follow it there.
- If the current project has no such block, run `npx oneup-standards init` and read the result before editing code.
- Skills are installed with `npx oneup-standards sync-skills`.
